## Course Overview

This course covers fundamental concepts and design patterns in software architecture. By the end of this course, students will be able to:

- Understand key architectural paradigms and concepts
- Implement design patterns (Creational, Structural, Behavioral)
- Evaluate and compare software architectures
- Apply architectural techniques to real-world software engineering problems

## Prerequisites

- Object-Oriented Programming (Java)
- Fundamentals of Software Engineering

## Textbooks

- Primary: "Software Architecture in Practice" by Len Bass
- Reference: "Design Patterns: Elements of Reusable Object-Oriented Software" by Gang of Four
